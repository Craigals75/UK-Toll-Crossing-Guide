Your information

Privacy policy

This policy explains what information may be processed when you visit UK Toll Crossing Guide.

Last updated: 28 August 2026

About the website

Independent information service

UK Toll Crossing Guide is an independently operated information website.

This website is not operated by a toll operator, government authority, tribunal, debt-recovery company, enforcement company or court.

The website currently provides read-only information and links to official external services.

Current website functions

Information collected directly by this website

The current version of UK Toll Crossing Guide does not require visitors to create an account, sign in or provide personal information to read its pages.

The website does not currently operate:

  • User accounts
  • A contact form
  • An evidence-upload service
  • An appeal-submission service
  • Online toll payments
  • Email newsletters
  • Advertising
  • Behavioural profiling
  • Independent website analytics
  • A comments or discussion system

The website owner does not currently ask visitors to provide names, addresses, vehicle registrations, payment details, appeal documents or other personal information.

This policy will be reviewed if the website changes

Before introducing contact forms, document uploads, newsletters, donations, advertising or analytics, the website’s privacy and cookie information will be reviewed and updated.

Website hosting

Information processed by GitHub Pages

UK Toll Crossing Guide is currently hosted using GitHub Pages, a service provided by GitHub.

GitHub states that when a GitHub Pages website is visited, the visitor’s Internet Protocol address is logged and stored for security purposes, whether or not the visitor is signed in to GitHub.

GitHub may also process technical information needed to deliver, secure and maintain its hosting service.

This information is processed by GitHub under its own privacy terms. The website owner does not receive a list of individual visitor IP addresses through the ordinary GitHub Pages service.

Read GitHub’s Privacy Statement (opens in a new tab)

Traffic information

GitHub repository statistics

GitHub may provide the repository owner with limited traffic statistics, such as:

  • Numbers of visits
  • Numbers of unique visitors
  • Popular pages
  • Websites that referred visitors
  • Repository views or downloads

These statistics are provided in an aggregated form and are used to understand general website use. They are not intended to identify individual visitors.

Read GitHub’s repository traffic guidance (opens in a new tab)

Cookies

Does this website use cookies?

The current website does not intentionally set its own advertising, analytics or personalisation cookies.

The mobile navigation script only opens and closes the navigation menu. It does not save information in the visitor’s browser.

The website does not currently use advertising networks, social-media tracking pixels or third-party analytics services.

Hosting and external services

GitHub or an external website may use cookies or similar technologies under its own policies. Visitors should check the privacy and cookie information provided by the relevant external service.

External links

Official payment and appeal websites

UK Toll Crossing Guide contains links to websites operated by toll operators, government organisations, tribunals and other third parties.

When you follow an external link, the destination website may collect information including:

  • Your IP address
  • Information about your device and browser
  • Payment and account information
  • Vehicle registration information
  • Appeal or notice information
  • Cookies and usage information

The relevant third party is responsible for explaining how it processes that information.

Visitors should check that an external website is genuine and read its privacy information before entering payment, account, vehicle or appeal details.

Appeal templates

Information entered into example wording

Appeal examples published on this website are ordinary page content. They do not transmit information to UK Toll Crossing Guide.

If you copy an appeal template and complete it on your own device, the completed information is not automatically sent to this website.

An appeal is submitted only when you send it through the relevant operator, authority, tribunal or court process.

Protect your documents

Do not publish unredacted notices, bank statements, vehicle documents, Blue Badges, benefit letters or court forms on social media or in a public GitHub discussion.

Personal details, references, registration numbers, barcodes and QR codes should be removed before documents are shared publicly.

Public GitHub repository

Information posted through GitHub

The website’s source-code repository may be publicly visible on GitHub.

If a visitor chooses to post an issue, comment or other contribution through GitHub, that activity is separate from simply visiting this website. It may be publicly visible and linked to the visitor’s GitHub account.

GitHub controls the account and platform information involved in that activity under its own privacy terms.

Visitors should not post toll notices, bank records, home addresses, vehicle registrations or other private information in a public repository.

Children

Information about children

This website is intended to provide general information to road users. It does not knowingly request or collect personal information from children.

Children should not submit personal information through any public GitHub feature or external toll service without appropriate assistance from a parent or guardian.

Security

Safe use of the website

The website is designed as a read-only information service and does not store visitor payment or appeal information.

Visitors should use only official operator websites when making payments or submitting personal documents.

No method of transmitting information over the internet can be guaranteed to be completely secure. Check the website address before providing confidential information.

Your rights

Data-protection rights

Data-protection law may give individuals rights concerning personal information held about them, including rights to:

  • Request access to personal information
  • Ask for inaccurate information to be corrected
  • Request deletion in certain circumstances
  • Request restriction in certain circumstances
  • Object to certain processing
  • Withdraw consent where processing relies on consent
  • Complain to the Information Commissioner’s Office

These rights are not absolute and depend on who is processing the information and why.

Because this website does not currently collect personal information directly, requests concerning information processed by GitHub should be directed to GitHub using the contact arrangements in its Privacy Statement.

A privacy contact method will be added if the website begins collecting personal information directly from visitors.

Complaints

Information Commissioner’s Office

The Information Commissioner’s Office is the UK regulator for data protection and information rights.

If your concern relates to information processed by GitHub or another external service, you should normally contact that organisation first.

You may also have the right to raise a concern with the Information Commissioner’s Office.

Visit the ICO complaint service (opens in a new tab)
